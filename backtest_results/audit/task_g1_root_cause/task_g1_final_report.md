## 1. Executive Summary & 10-Cause Attribution Verdict

Why did the baseline `goldedge_backtest_medium_2026-11-21.csv` (`bt_20261121_191649_a03728`) earn only `+$162.25` UI-rounded (`+$162.2590` full precision) on `70` trades before triggering the `8%` HWM kill-switch (`-$885.52` / `8.0154%`) on `2026-10-26 13:36:14Z`?

Root-cause attribution across all 10 candidate hypotheses in the prompt (grounded in Phase 1–5 verification):

1. **Backtest Implementation Defects (`E1–E6, E8` — CONFIRMED):**
   - `E1`: Inverted/non-positive quotes (`11,612` rows) reached `kalman.update_tick` in exit scans before B4 validation, changing `3/70` trades (`-$17.74` drag).
   - `E2`: Soft `KALMAN_VELOCITY_REVERSAL` ran before hard `SL`/`TARGET`, missed `mtm_tracker` updates on Kalman exits, and returned `len(bids)-1` on timeout/early-fail instead of last valid tick.

2. **Ineffective Trade Scoring (`score >= 0.80` — PRIMARY ENTRY ROOT CAUSE):**
   - `28` trades with `score >= 0.80` lost **`-$439.86`** (`46.43%` WR, **`9/13` full SL exits**, mean `|ema20_dist_atr| = 1.693`), while `42` trades with `score in [0.60, 0.80)` earned **`+$602.12`** (`59.52%` WR, `PF 1.643`, `4` SL exits). 3. **Kalman Filter Exit Calibration (`atr_per_tick = max(atr/60.0, 0.01)` — CONFIRMED INTERACTING FLAW):**
   - Exit-minute valid tick count averages `244.7/min` (median `235.5`, `max 434`, `~4×` the hardcoded `/ 60.0` assumption), producing premature exits as fast as `5.3s`. However, disabling `use_kalman_exit` *without* fixing `score >= 0.80` (`H1_STD_EXIT`) fails `VAL` (`-$600.28`, halting `2026-10-20`) and underperforms in Holdout (`+$126.77`), whereas **capping `score < 0.80` WITH Kalman exit ON (`H3b_KAL_CAP80`)** cuts toxic entries AND keeps Kalman damage control, winning every split (`+$1,584.43` `FULL`, `+$602.65` `HO`, `4.16%` DD).
4. **Incorrect / Lagged Market Regime Detection & Warmup Void (`CONFIRMED CONTRIBUTOR`):**
   - `18/70` entries where `raw_regime != committed_regime` (2-bar hysteresis lag) lost **`-$335.35`** (`44.4%` WR) vs `52` aligned entries **`+$497.61`** (`57.7%` WR).
